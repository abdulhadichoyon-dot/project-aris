# Project Aris — God-Level Bio Page

A standalone, responsive bio/landing page for Project Aris using the supplied anime artwork as the visual language.

## Files
- `index.html` — page structure and content
- `styles.css` — full visual system, responsive layout, effects and animations
- `script.js` — scroll reveals, active navigation and image lightbox
- `assets/` — five supplied source images

## Run
Open `index.html` directly in a browser. No build step is required.

For GitHub Pages, upload the complete folder contents to a repository and enable Pages from the repository's branch settings.

## Customize
Change the hero copy, button destinations, text labels and image order in `index.html`. Keep all asset paths inside `assets/` unchanged unless you also update the HTML references.
